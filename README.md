# 🧭 TikTok Explore Page Replica

A high-fidelity, responsive clone of the TikTok Explore interface built for modern browsers. 🚀

## ✨ Features
🎬 **Dynamic Video Grid**: Interactive thumbnails with hover zoom animations. 🎥
📱 **Fully Responsive**: Optimized for Desktop, Tablet, and Mobile layouts. 📱
🌗 **Authentic Dark Mode**: Matches TikTok's signature black and red color palette. 🌑
🔘 **Interactive Tabs**: Functional category switching using jQuery and dynamic rendering. ⚡
🔍 **SEO Optimized**: Semantic HTML5 and meta tags for improved search visibility. 🌐
🎨 **SVG Powered**: Lightweight, crisp icons for faster loading times. 🏎️
📂 **Flat Structure**: All files sit in the root for easy deployment and hosting. 📁

## 🛠️ Tech Stack
* **HTML5**: For semantic layout. 🧱
* **CSS3**: For custom styling and smooth animations. 💄
* **JavaScript & jQuery**: For DOM interaction and mock data logic. 🧠
* **Bootstrap 5**: For the responsive grid system. 📏
